# Third-party dependencies

Das Repository vendort keine externen Bibliotheken. PlatformIO lädt die jeweiligen Abhängigkeiten beim Build.

Aktuell:

- WebSockets (Links2004)
- ArduinoJson (Benoit Blanchon)
- Arduino_GFX (Waveshare-Displayprofil)
- arduino-audio-driver (Waveshare-Audiocodecs)

Vor einer öffentlichen Veröffentlichung sollte die Projektlizenz zusammen mit den Lizenzbedingungen der Build-Abhängigkeiten final festgelegt werden.

## FutureProofHomes Satellite1.1

Das Satellite1.1-Profil orientiert sich an öffentlich dokumentiertem Pinout, Audioformat und XMOS-Steuerprotokoll aus den offiziellen FutureProofHomes-Projekten. Es wird keine FutureProofHomes-XMOS-Firmware in diesem Repository mitgeliefert.

- https://github.com/FutureProofHomes/Satellite1-ESPHome
- https://github.com/FutureProofHomes/Satellite1-Hardware
- https://docs.futureproofhomes.net/satellite1-introduction/
